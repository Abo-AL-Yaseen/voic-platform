# بنك معلومات VOIC ودليل الاستخدام

أُعدّ بتاريخ 13 نوفمبر 2026. هذه حزمة بحث وتعليمات لفيجما AI؛ لا تعني تنفيذ الصفحات أو اعتماد الشركة للمحتوى بعد.

## الاستخدام

1. افتح نفس مشروع VOIC ونفس محادثة Code Layer الحالية.
2. انسخ كامل ملف VOIC_Master_Prompt.md إلى Ask for changes. البيانات والتعليمات موجودة في نفس البرومت.
3. أرفق الصور داخل assets عند الحاجة، أو ارفع الملفات منفردة إذا واجهة فيجما لا تقبل ZIP. لا يلزم إعادة رفع الصور الموجودة أصلًا بالمشروع.
4. احتفظ بنسخة من الحالة الحالية قبل التنفيذ. إذا توقف فيجما بسبب الرصيد أو حدود السياق، اطلب متابعة نفس المهمة من آخر نقطة دون إعادة البناء.
5. راجع نتيجة الصفحات وروابطها فعليًا؛ البرومت الشامل لا يضمن اكتمال مشروع كبير في استجابة واحدة.

## محتويات الحزمة

- البرومت الرئيسي: تعليمات للصفحات التسع الأساسية، بما فيها صفحات التفاصيل الديناميكية، العربية والإنجليزية، والاختيار والمقارنة والاستفسارات.
- research/product-bank.json: 11 سجل منتج، أحجام واستخدامات ووصف وبيانات داخلية للمصدر والاختلافات.
- research/recipe-bank.json: أربع وصفات مختصرة مأخوذة من صفحات الشركة، مع المقادير والخطوات والصور والمنتجات ذات الصلة حيث وردت.
- research/contact-bank.json: وسائل اتصال وروابط اجتماعية مستخرجة من مصادر الشركة.
- assets: 22 صورة أصلية للمنتجات والطعام والمصنع والتاريخ.
- asset-sources.json: خريطة الصور ومصادرها؛ للاستخدام الداخلي فقط.

## ما تمت مراجعته

- الموقع الرسمي الإنجليزي وصفحات المنتجات التي أمكن فتحها، وصفحات التاريخ والتواصل والجودة.
- صفحة QR وروابط الاتصال والاجتماعيات المرتبطة بها.
- EN Catalog 4.pdf، ثماني صفحات، نصًا وصورًا.
- catalouge 71 years final 2025.pdf، عشر صفحات، مع مراجعة مرئية لبيانات العبوات.
- صفحات الوصفات العربية؛ اُختيرت أربع وصفات قابلة للاستخدام، واستُبعدت الوصفات ذات المقادير الناقصة أو الارتباطات المربكة.
- ملف فيجما والسياق المصور المتاح. أحدث تقرير التنفيذ مصدره فيجما؛ لم تُعَد اختبارات الكود الأحدث في هذه الحزمة.
- لم يتيسر فحص جميع منشورات Instagram وFacebook؛ لا ندعي مراجعة جميع المنشورات أو كل رابط خارجي.

## قرارات المحتوى

لا تظهر المصادر أو شارات التوثيق أو خلافات البحث للزوار. تظهر المعلومات التجارية المعروفة فقط. البيانات الناقصة تُحذف من الواجهة وتبقى أسئلتها داخلية. لا أسعار أو شراء أو ادعاءات تصدير أو شهادات حالية غير معتمدة. الاستفسار يجهز رسالة بريد ولا يدعي إرسالها.

## أسئلة الشركة المتبقية

- صورة أصلية معتمدة لصن غولد.
- أحجام وعبوات الغزالين وريم وصن غولد؛ لا تُستنتج من صورة العبوة.
- اعتماد أحجام الغزال عند اختلاف الكتالوج عن الموقع، ووصف عبوة البلقاء.
- اعتماد المكونات النهائية الخاصة بكل منتج قبل النشر التجاري؛ بعض النصوص ترجمة تحريرية، ولا تُعد ملصقًا غذائيًا معتمدًا.
- بيانات التغذية والحساسيات والتخزين والصلاحية غير المتاحة تُحذف، ولا تُخمن.
- تأكيد التشكيلة التجارية الحالية ومنتجات الموقع الأقدم، ومتطلبات أي توريد إلى ألمانيا من الشركة.
- لا عنوان مكتب ألماني ولا موزع ولا موافقات أو مدة شحن أو حد أدنى للطلب دون بيانات فعلية.

## حدود التحقق

فُحصت بنية ملفات JSON، عدد السجلات، سلامة الصور وإحالات صور الوصفات والحزمة. لا تتضمن هذه المهمة بناء التطبيق أو اختبارات متصفح لصفحات لم ينفذها فيجما بعد.
